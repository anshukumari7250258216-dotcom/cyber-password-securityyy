🚀 About the Project

CyberShield is an academic Cyber Security project designed to help users understand password strength, estimate password entropy, and generate stronger random passwords.

The application performs password analysis directly in the browser without sending the entered password to a server.

✨ Features

- 🔐 Real-Time Password Strength Analyzer
- 📊 Password Entropy Estimation
- ⚡ Secure Random Password Generator
- 👁️ Show/Hide Password Option
- 📋 Copy Generated Password
- ✅ Password Security Checklist
- 📱 Responsive User Interface
- 🔒 Client-Side Password Processing

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Crypto API
- Vercel (Deployment)

🔐 Privacy & Security

- Password analysis runs in the browser.
- Passwords are not intentionally transmitted to a backend server.
- Generated passwords use the browser's Web Crypto API.
- Never enter your real banking or personal account passwords into a demonstration website.

Note: Entropy is an estimate based on character-set size and password length. It does not account for every real-world guessing strategy.
